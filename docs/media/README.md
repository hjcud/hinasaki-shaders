# Demo media

Full-length GIF conversions of three videos in the original Hinasaki tear shader announcement thread, published on April 10, 2023.

| GIF | Source author | Original post | Source duration |
|---|---|---|---|
| [teardrop-apollo.gif](teardrop-apollo.gif) | @mbM0001_ | [Apollo demonstration](https://x.com/mbM0001_/status/1645361384719540226) | 10.45 s |
| [teardrop-controls.gif](teardrop-controls.gif) | hjcud | [Material controls](https://x.com/i/status/1645361618661052416) | 63.916 s |
| [teardrop-uv-preview.gif](teardrop-uv-preview.gif) | hjcud | [2D UV preview](https://x.com/i/status/1645361804070232065) | 46 s |

The first video is attached to the announcement; the other two are in the developer's replies in the same conversation.

## Conversion

- Source: the highest-resolution direct MP4 available for each post, 1280 × 720.
- Output: 768 × 432, 12 frames per second, up to 128 palette colors.
- Full duration, original aspect ratio, no cropping, infinite loop, no audio.
- GIF frame-delay rounding produces durations of 10.50 s, 63.91 s, and 46.00 s respectively.
- Original footage content was not retouched. Only frame rate, dimensions, and color palette were reduced for the previews.
- Original MP4 downloads are kept locally; the repository contains the GIF previews.

These attributed demo videos and their GIF derivatives are presentation media, not shader source code. They are excluded from the repository's Apache-2.0 software license; no additional license to the source footage or depicted avatar artwork is granted here.
